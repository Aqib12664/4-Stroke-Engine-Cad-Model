## 📌 Overview
This repository contains a complete 3D mechanical CAD model of a 4-stroke engine. The project encompasses the individual design of all core moving internal combustion components and their final functioning assembly. It was developed to demonstrate precision 3D modeling, orthographic projection, and mechanical assembly techniques.

## 🛠️ Components Modeled
The engine assembly consists of the following meticulously designed parts (all source `.dwg` files are included in this repository):
*   **Piston Sub-assembly:** Piston, Piston Pin, and Piston Rings
*   **Connecting Rod Sub-assembly:** Connecting Rod and Connecting Rod Cap
*   **Crankshaft Sub-assembly:** Crankshaft and Crankweb
*   **Final Assembly:** Fully mated and aligned engine block components

## 🎓 Project Background
This model was designed as a comprehensive first-semester project for the Mechatronics Engineering program at the College of Electrical and Mechanical Engineering (CEME), NUST. It serves as a practical application of computer-aided design principles for complex mechanical systems.

## 💻 Software Used
*   **Autodesk AutoCAD:** Used for all 2D sketching, 3D solid modeling, and final assembly alignment.

## 📂 Repository Structure
*   `/DWG_Models/`: Contains all native AutoCAD `.dwg` files for individual parts and the final assembly.
*   `/Renders/`: Contains exported images, PDFs, and orthographic projections of the CAD models.

## 🚀 How to View
To view or modify the original CAD files:
1. Clone or download this repository to your local machine.
2. Ensure you have Autodesk AutoCAD (or a compatible DWG viewer) installed.
3. Navigate to the `/DWG_Models/` directory and open `assembly.dwg` to view the complete assembled engine.
